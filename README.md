SHAAL VIKAS

About the Project

Shaale Vikas is an Android application that I worked on during my internship.

The main idea of this application is to create a bridge between schools and alumni. The application helps schools keep track of alumni support and contributions.

The project was developed using Android development technologies and Firebase.

Main Idea

The application is designed to connect schools with their alumni and make it easier to manage alumni contributions and activities.

Some of the main features planned in the application are:

Dashboard

Progress Tracking

Pledge System

Before and After Gallery

Donor Hall of Fame

Technologies Used

Kotlin

Jetpack Compose

Firebase

Firebase Authentication

Firebase Firestore

Firebase Storage

Android Studio

Project Features

Dashboard

The dashboard provides an overview of the application and important information.

Progress Tracking

This feature helps to track the progress of school development activities and contributions.

Pledge System

Alumni can support the school by making pledges or contributions.

Before and After Gallery

This section shows the changes and improvements made with the support received from alumni.

Donor Hall of Fame

This section recognizes alumni and donors who have contributed to the school.

Firebase

Firebase was used for storing and managing application data.

The project uses Firebase services such as:

Firebase Authentication

Cloud Firestore

Firebase Storage

My Role

I worked on the Android application development and implemented the application screens and functionality using Kotlin and Jetpack Compose.

I also worked with Firebase for authentication and storing application data.
